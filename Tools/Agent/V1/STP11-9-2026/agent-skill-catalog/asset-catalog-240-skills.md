# Agent Skill Catalog

Canonical capability data for this Skill Tool: 240 skills across 24 categories.
Layout: `## <n>. <Category>` headings followed by numbered `Skill Name` entries with a `Description` line.
Human-editable. The parser also accepts raw copied catalog text, Markdown lists, and copied HTML.

## 1. Reference Intelligence and Source Libraries

1. Skill Name: Reference Library Navigator
Description: Search saved reference files before open-web research, identify category-matched sources, remove duplicates, flag stale entries, and return the best known links with concise usage notes.

2. Skill Name: Reference Catalog Builder
Description: Create and maintain category-named Markdown or text files containing links, documentation, datasets, repositories, archives, and human notes in a consistent schema.

3. Skill Name: Reference Ingestion Assistant
Description: Accept links or files added by a developer or AI, normalize titles and URLs, assign categories and tags, and append them without damaging existing entries.

4. Skill Name: Source Priority Router
Description: Choose between saved references, connected sources, official documentation, scholarly databases, and general search using explicit trust and freshness rules.

5. Skill Name: Link Health Auditor
Description: Check saved URLs for redirects, dead pages, access restrictions, domain changes, and replacement locations; produce a repair queue without silently deleting history.

6. Skill Name: Web Archive Locator
Description: Locate archived snapshots and mirror records for removed or changed pages, record snapshot dates, and warn when archived material may be incomplete.

7. Skill Name: Reference Deduplicator
Description: Detect exact and near-duplicate URLs, canonicalize tracking parameters, merge annotations, and preserve the strongest version of each source record.

8. Skill Name: Source Provenance Recorder
Description: Record who added a source, when it was added, why it matters, its original location, license notes, and later verification events.

9. Skill Name: Topic Reference Packager
Description: Bundle selected reference files for one task or agent, with a compact index, priority ordering, and instructions for progressive loading.

10. Skill Name: Reference Gap Finder
Description: Compare a research goal with the saved library, identify missing source types or perspectives, and propose targeted additions rather than broad searching.
