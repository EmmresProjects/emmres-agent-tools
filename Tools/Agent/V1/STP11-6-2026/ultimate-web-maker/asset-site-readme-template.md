## Run locally

No package manager, build step, network access, or third-party runtime dependency is required for this static starter.

From a POSIX shell (`sh` or `bash`) in this project directory, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser. Stop the local server with `Ctrl-C`.

## Files

- `index.html` — semantic page content and metadata.
- `styles.css` — responsive layout, design tokens, focus treatment, and reduced-motion handling.
- `app.js` — accessible small-screen navigation only; the page content remains available without JavaScript.

## Before publishing

This is a static local starter, not a deployed site or a substitute for project review. Replace or approve all copy and brand tokens, verify the document language, test keyboard and assistive-technology use, check real browser/device layouts, and add only integrations that have been reviewed. No payment, account, analytics, backend, DNS, hosting, or deployment service is configured. Obtain owner approval before publishing or connecting production services.
