Category 7: Context and Memory Management

  1. 1. Skill Name: Context Packager
    Description: Assembles the smallest useful context bundle for a worker while preserving decisions, constraints, and provenance.
  2. 2. Skill Name: Checkpoint State Saver
    Description: Captures recoverable mission state at defined boundaries so interrupted work can resume without repeating completed tasks.
  3. 3. Skill Name: Cross-Task Memory Firewall
    Description: Prevents unauthorized context sharing between tasks unless a validated handoff explicitly grants access.

CSS classes, data attributes, tags, and numbering must not become capability names.
