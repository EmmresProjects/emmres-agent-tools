# Upload checklist

- [ ] Copy tool folders into the correct category.
- [ ] Remove secrets, private data, caches, and generated environments.
- [ ] Preserve required third-party licenses and notices.
- [ ] Complete package READMEs and metadata.
- [ ] Update the manual documentation catalog and category pages.
- [ ] Configure Git LFS before committing any large binary.
- [ ] Commit and push with GitHub Desktop.
- [ ] Enable GitHub Pages from `main` and `/docs`.
- [ ] Test every published link in a private browser window.
- [ ] Add the GitHub Pages URL as an Agent Builder public website source.
